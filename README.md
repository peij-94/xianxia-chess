## 一、 16-Bit 像素国风美工重构体系

本项目已彻底重构为**纯正的国风仙侠复古像素美学（16-Bit Pixel Art）**，还原经典 GBA / SNES 东方策略战棋奇幻质感：

1. **逐像素手绘角色精灵（Pixel Sprites）**：
   - **太虚剑仙 · 凌虚子**：道冠白袍，身侧悬浮发光金色像素飞剑（呼吸沉浮微动帧）。
   - **青丘天狐 · 白浅**：粉白仙裳，毛茸茸多簇像素狐尾摇曳微拂，手持回天宝珠。
   - **南山神禽 · 毕方**：独足金爪神鸟，展翼赤焰飞羽，白喙金冠。
   - **荒古凶兽 · 祸斗**：黑色猎犬身躯，赤瞳獠牙，背脊燃烧亮黄橙红像素烈焰。
   - **鹿吴凶禽 · 蛊雕**：独角巨鹰，金羽钢爪，凌空俯冲。
   - **荒古四凶 · 梼杌**：重装玄岩石铠霸气巨角，体型大一号的 Boss 压迫感。
2. **像素地貌瓦片系统（Pixel Tileset）**：
   - 凡土平原（青苔碎石阶）、水华灵泉（涟漪波动波纹）、祝融火脉（玄武岩岩浆脉冲裂缝）、建木林（古木阴影与灵木叶片）、玄黄巨岩（立体高低差断崖）。
3. **像素粒子与视觉反馈（Pixel VFX）**：
   - 像素金光飞剑斩裂、像素爆燃火焰方块、翠绿仙露十字星上升、壁击碎石方块飞溅。
   - 像素风格描边伤害浮字（【暴击】、【相克】、【壁击】）。
4. **高清像素头像图鉴（256×256 Pixel Portraits）**：
   - 已生成并切割出 6 位角色专属像素肖像图片，嵌入玉简详情与选关战役。
5. **国风仙侠芯片音效与音乐（Chiptune Xianxia Audio）**：
   - 基于 Web Audio API 算法合成方波与三角波五声音阶琶音，经典仙侠战斗听感。

## 二、 游戏系统与玩法深度（全套完成）

1. **六大山海经主线战役章节（Campaign System）**：
   - **第一回：青丘之野 · 凶潮初现**（初遇祸斗群，熟悉走位与五行生克）
   - **第二回：章莪之山 · 讹火连天**（祝融火脉密布，火系伤害暴增，水克火破阵）
   - **第三回：昆仑之渊 · 封魔决战**（决战四凶【梼杌真身】双血槽 Boss，高防御全屏撼地）
   - **第四回：北山大泽 · 相柳毒沼**（决战九首巨蟒【相柳】，2x2 群体腐蚀毒沼）
   - **第五回：邽山之阴 · 穷奇嗜风**（决战恶虎飞翼【穷奇】，嗜血扑杀对残血斩杀且击杀再动）
   - **第六回：章尾之巅 · 烛龙定鼎**（终极迎战【烛九阴】，掌控太古昼夜轮转，阴阳极光天罚）

2. **新增荒古神魔异兽机制**：
   - **相柳（九首水毒神魔）**：九首水毒喷吐范围 2x2 毒泽，造成水系范围伤害并腐蚀目标防御。
   - **穷奇（荒古四凶之二）**：嗜血扑杀，对气血低于 40% 的目标增伤 50%，若成功击杀目标则立即恢复真元并重置行动回合（嗜血狂性连斩）！
   - **烛九阴（章尾天祖）**：太古睁暝·逆转阴阳！
     - 🌞 **张目为昼**：全屏烈阳普照，暴击率提升 30%，庚金与烈火系法术伤害加深 25%！
     - 🌙 **闭目为夜**：全屏九幽玄夜，视野与移动步法受抑 -1，水木回春生机疗愈提升 40%！

3. **五藏山经 · Roguelike 随机秘境潜修模式**：
   - **五层地脉层进**：南山、西山、北山、中山、章尾神山，动态程序化生成地脉与敌群。
   - **三选一远古遗宝（Relics）**：
     - `河图洛书残页`：开局推演天机，真元额外 +2；
     - `祝融烈焰神令`：攻击额外附加 18 点神火真伤；
     - `昆仑万剑灵髓`：受创反震 25% 金系穿透反伤；
     - `九畿建木灵根`：每回合初全员恢复 20 点气血；
     - `刑天不屈战戚`：气血低于 50% 时必触发 100% 暴击；
     - `乘黄腾云吉光`：步法 +1，闪避概率 +20%。
   - **山海奇遇奇闻事件（Events）**：偶遇瑞兽当康、昆仑断刃剑冢、瑶池仙境甘露，双向抉择影响气血、灵石与遗宝。

4. **东方五行生克与绝脉背刺**：
   - 金克木、木克土、土克水、水克火、火克金（增伤 35%，受抑减伤 25%）。
   - 绝脉背刺 140% 伤害必暴击！
   - 技能击退推入巨岩触发二次崩解真实伤害！
   - 友军阵营保护：范围伤害技能友军完全免疫，治疗技能仅能作用于友方。

5. **大荒同调 · 羁绊合击技（Beast Resonance）**：
   - 修仙者与契约兽相邻（2 格内）时，普攻或施法触发同调追击，伤害额外提升 25%！

6. **踏星悔棋功能（Undo Move）**：
   - 玩家移动后未施法前，随时点击【↶ 悔棋】或点击鼠标右键回到起步点，轻松尝试最优走位。

7. **天衍灵石与境界突破系统（Cultivation Breakthrough）**：
   - 战役胜利获得灵石奖励，消耗 100 灵石全体突破境界（金丹 -> 元婴 -> 化神），全属性暴涨，解锁终极突破奥义！

## 三、 网页版 Demo 体验与操作指引

纯原生前端打造，完美支持 60FPS 逐像素渲染与合成音效，双击打开或运行脚本即可体验。

### 本地快速启动：
- **网页版 Demo 体验**：
  ```bash
  ./start_web_demo.sh
  ```
  *或者直接在浏览器打开：* [`web_demo/index.html`](file:///Users/peij94/Documents/antigravity/修仙战棋/web_demo/index.html)。

- **Godot 4 桌面端直接运行**：
  ```bash
  ./start_godot.sh
  ```
  *或者在 Godot 4 编辑器中打开 `godot_project/`，按 F5 即可直接运行主场景 `res://scenes/Battlefield.tscn`。*

## 五、 Godot 4 引擎对应工程

位于 [`godot_project/`](file:///Users/peij94/Documents/antigravity/修仙战棋/godot_project/)：
- `project.godot`：Godot 4 工程配置（已启用 Nearest 像素纹理采样与 1280×720 视口）。
- `shaders/InkWashPixel.gdshader`：16-Bit 国风像素水墨粒子着色器。
- `scenes/vfx/`：GPUParticles2D 像素斩击、相柳毒沼、烛龙极光粒子特效场景。
- `assets/images/`：存放全套 9 位角色/神兽 16-Bit 像素头像与海报资产。
- `scripts/combat/CombatResolver.gd`：GDScript 五行生克与背刺撞击伤害结算。
- `scripts/grid/GridManager.gd`：GDScript BFS 寻路与地脉网格。
- `scripts/entities/Unit.gd`：修士与山海异兽实体类。
- `scripts/core/CampaignManager.gd`：六大主线战役关卡与五藏山经 Roguelike 动态生成器。
- `scripts/core/ResonanceSystem.gd`：大荒同调合击判定。
- `README_GODOT.md`：详细的 Godot 导入与研发说明。
