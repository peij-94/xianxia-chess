# 《山海问道录·天衍棋局》游戏设计案 —— 第六卷：本命神兵法宝与武器锻造系统设计

## 一、 系统定位与设计理念

在传统修仙与《山海经》古典神话体系中，**法宝神兵**是修士斩妖除魔、参悟天道不可或缺的本命重器。
本作构建了**“本命神兵法宝系统”**（Xianxia Divine Weapon System），旨在深化修仙战棋的策略构筑与战前/战中配置深度：

1. **五行相性与角色羁绊契合**：每件神兵法宝附带天道五行法则（金、木、水、火、土、混沌全相），与角色属性产生共振。
2. **三维立体属性增益**：不仅提供攻击（ATK）、防御（DEF）基础属性，还直接影响移动力步法（Move Range）、最大真元灵气（Max Qi）与致命暴击率（Crit Rate）。
3. **独门专属被动神诀（Passive Affixes）**：赋予独一无二的战术机制，如击退距离递增、壁击眩晕、范围自愈、灼烧扩散、破甲穿透与移动迟滞。
4. **即时动态切换与数值同步**：战局中与战前整备界面均支持法宝切换，角色面板与战斗数值即时无缝联动。

## 三、 神兵法宝背景典故与玄门器韵

### 1. 太白青锋剑 (`sword_taibai`)
- **典故**：昆仑太虚剑宗镇派重宝，引九天太白金曜陨铁淬炼千载，剑身通体霜白冷冽，出鞘如惊雷破晓。
- **契合修士**：太虚剑仙 · 凌虚子。与【庚金破空剑】协同可打出超远贯穿击退，将敌人推向障碍物触发毁灭性壁击。

### 2. 九尾回天绫 (`silk_nine_tail`)
- **典故**：青丘九尾天狐一族传承仙绫，以长生建木天蚕丝与天狐本命灵毛织就，流光溢彩，触之生机盎然。
- **契合修士**：青丘天狐 · 白浅。极大增强【万木逢春】与【青丘狐魅】的治愈与牵引效果，阵地战全员回春核心。

### 3. 赤羽三昧琴 (`zither_flame`)
- **典故**：以章莪山焦尾梧桐神木为身，毕方真火蜕羽为弦斫制而成。抚弦轻拨，音如凤鸣九天，漫天赤羽化作三昧神火。
- **契合神兽**：南山神禽 · 毕方。暴击时在目标周围蔓延三昧真火，配合【独足赤羽焰】形成毁灭性火海。

### 4. 玄冥幽水戈 (`halberd_abyss`)
- **典故**：采北山大泽九幽万丈寒渊之生铁熔铸，戈刃森白凝霜，触体瞬结玄冰，冰封经脉真元。
- **战术价值**：控制流神兵，命中削减敌人步法，使其无法近身或脱离危险区域。

### 5. 番天镇岳印 (`seal_fantian`)
- **典故**：远古大能采不周山半截残峰神石炼化，祭出时化作巍峨万仞山岳泰山压顶，万法难侵。
- **战术价值**：肉盾防御流神兵，提供超高物防与巨额近战反震，重装推进必备。

### 6. 开天乾坤枪 (`spear_chaos`)
- **典故**：混沌初开、鸿蒙未判之时的天地本源灵枪，蕴含太虚两仪混沌母气。枪锋一出，阴阳颠倒，万劫归墟。
- **战术价值**：全能神品兵刃，无视防御与相克加深，任何流派装备皆可质变为战场核心杀神。

## 四、 16-Bit 像素图标规范与生成标准

为保证与全游戏复古国风 16-bit 美学完全统一，武器图标采用以下美术规范：
1. **尺寸与网格**：
   - 基础源尺寸：`32 × 32` 或 `48 × 48` 像素。
   - 严格像素对齐：禁止浮点抗锯齿与模糊半透明过渡，使用 1px/2px 纯色阶梯块构图。
2. **色阶分层（4~5 级离散色阶）**：
   - 剑身/锋芒：外围深色描边 → 暗调金属底色 → 亮调反光面 → 极白高光点。
   - 法宝流光：采用对应五行的标志性国风色调（金黄、竹青、霁蓝、朱砂赤、赭黄、玄紫）。
3. **程序化与图片资源双轨容错**：
   - 在 [`WeaponSystem.gd`](file:///Users/peij94/Documents/antigravity/修仙战棋/godot_project/scripts/core/WeaponSystem.gd) 中预留统一的武器映射表与路径解析，优先加载 `res://assets/weapons/*.png` 贴图；若外部贴图未就绪，系统自动以 CanvasItem 矢量像素指令与 Emoji 绘制高保真备用图元。

## 五、 技术实现架构与数值联动流

```
   ┌────────────────────────────────────────────────────────┐
   │             WeaponSystem (Refdata Manager)             │
   │  WEAPONS 字典表配置: 属性、被动加成、相性、Icon路径    │
   └───────────────────────────┬────────────────────────────┘
                               │
               equip_weapon(weapon_id)
                               │
                               ▼
   ┌────────────────────────────────────────────────────────┐
   │                    Unit (Entity)                       │
   │  1. 记录 base_attack, base_defense, base_move_range    │
   │  2. 叠加武器加成: attack = base + atk_bonus ...        │
   │  3. 刷新真元与气血上限                                 │
   │  4. queue_redraw() 触发头顶装备法宝微标刷新            │
   └───────────────────────────┬────────────────────────────┘
                               │
              _draw_unit_panel() / combat
                               │
                               ▼
   ┌────────────────────────────────────────────────────────┐
   │               Battlefield HUD & Combat                 │
   │  1. 详情面板实时刷新攻击、防御、暴击与被动技能描述     │
   │  2. 伤害结算器 (CombatResolver) 计算武器特效与破防     │
   └────────────────────────────────────────────────────────┘
```

1. **装备切换接口**：
   - `Unit.equip_weapon(weapon_id: String) -> void`
   - 保存角色的未穿戴原始属性 `sync_base_stats()`，切换时基于基准属性重新计算加成，杜绝属性无限叠加 Bug。
2. **伤害结算联动**：
   - 在 [`CombatResolver.gd`](file:///Users/peij94/Documents/antigravity/修仙战棋/godot_project/scripts/combat/CombatResolver.gd) 中结算伤害时，读取装备武器的 `passive_name` 与加成系数，自动计算相克加深、破甲与被动效果。
