# 《山海问道录·天衍棋局》游戏设计案 —— 第七卷：大荒四时天象（天气系统）与战术障碍物地貌设计

## 一、 系统定位与世界观立意

《山海经·大荒西经》云：“有人名曰石夷，来风曰韦，处西北隅以司日月之长短。”
在大荒修仙文明中，天人感应、四时运化是天地大道的体现。战场绝非一成不变的静止方格，而是随着**四时天象轮转**与**山海秘境地脉**产生生生不息的动态交互：

1. **大荒四时天象（Weather System）**：全场环境光影与法则流转，强化特定五行道法，压制相克属性，打破战术定势。
2. **战术地貌与障碍物（Tactical Obstacles）**：古剑残碑、赤火晶柱、玄冰刺、毒荆棘与万仞岩峰错落分布，提供掩体遮挡、战术卡位与推撞壁击连招空间。
3. **五大山海秘境场景（Biomes）**：剑冢、火谷、神林、寒潭、仙府，赋予整场战斗全局法则被动。

## 二、 大荒四时天象（天气系统）设计详则

战场天气每 3~4 回合进行一次天象衍化（或由神魔专属神通如烛九阴【太古睁暝】强行逆转）。

| 天象ID | 天象名称 | 标志图标 | 色相渲染色调 (`ColorModulate`) | 天象核心机制与战斗法则 |
| :--- | :--- | :--- | :--- | :--- |
| `CLEAR` | **天朗气清 · 乾坤泰和** | ☀️ | `#ffffff` (纯白标准光照) | 阴阳谐和，大荒祥瑞。全员聚气吐纳正常，无特殊气候加成与减益。 |
| `LIGHTNING` | **紫霄雷暴 · 九天掣电** | ⚡ | `Color(0.85, 0.78, 1.15, 1.0)` (紫霄玄雷光) | **九天神雷滚滚**：金系神通伤害+25%；攻击暴击时引动【九天引雷】，对目标周围1格敌方造成连锁雷煞伤害！ |
| `RAIN` | **灵气仙霖 · 碧水甘露** | 🌧️ | `Color(0.80, 0.95, 1.05, 1.0)` (青霖水汽清光) | **青霖仙露润泽**：水系与木系神通真元消耗-1；每候回合结束全体友军自愈+15气血与+1真元；火系威能-20%。 |
| `HEATWAVE` | **烈阳天煞 · 旱魃炽炎** | 🏜️ | `Color(1.18, 0.92, 0.75, 1.0)` (赤阳炎灼焦黄) | **赤阳当空，大地熔铸**：火系神通威能+35%；攻击命中附带【真火灼烧】；水系治疗效果-30%；全员真元聚气+1。 |
| `FOG` | **太阴寒雾 · 迷踪幻境** | 🌫️ | `Color(0.85, 0.90, 0.96, 0.96)` (九幽迷雾清冷) | **九幽寒雾笼罩**：全体步法+1；获得20%【迷雾闪避】几率；射程大于2格的远程神通威力-25%。 |

### 动态环境渲染表现
- 画面通过底层 `CanvasModulate` 或场景根节点材质平滑插值（Tween 0.8s）进行柔和渐变过度，营造真实昼夜与气候变幻氛围。
- 顶部 HUD 专设**【大荒四时天象仪】**，实时显示当前天象名称、剩余回合数与详细法则增益 Tooltip。

## 三、 战场战术障碍物地貌设计详则

战场不再仅仅是平铺的平地与水火灵脉，新增 5 种兼具**掩体功能**与**元素互动**的 16-bit 像素战术障碍物：

```
                    ┌──────────────────────────┐
                    │    战术障碍物五大类型    │
                    └─────────────┬────────────┘
         ┌──────────────┬─────────┴───────┬──────────────┬─────────────┐
         ▼              ▼                 ▼              ▼             ▼
   【玄黄万仞岩】 【通天古剑残碑】 【祝融赤火晶柱】 【太阴玄冰极刺】 【幽煞剧毒荆棘】
    (STONE_WALL) (SWORD_MONUMENT)  (FIRE_PILLAR)  (FROST_SPIKE)  (THORN_VINES)
    天然硬掩体     金系共振/反伤     火系殉爆真伤   寒气减速/冻结   剧毒腐蚀/护甲削减
```

### 1. 玄黄万仞岩峰 (`STONE_WALL`)
- **地貌特征**：荒古息壤与玄武岩层隆起形成的坚固岩柱，表面风化剥落，具厚重立体断崖质感。
- **战术机制**：完全阻隔直射弹道与步行寻路；可作为绝佳防守掩体；遭受击退推撞时造成二次【崩解粉碎真实伤害】。

### 2. 通天古剑残碑 (`SWORD_MONUMENT`)
- **地貌特征**：上古剑仙飞升或陨落插立于大荒地脉中的巨型断剑残碑，剑身铭刻上古剑篆，隐隐散发庚金光晕。
- **战术机制**：阻挡寻路。周围 1 格内的金系修士出招时引发【剑气共鸣】，额外造成 15% 剑气穿透。

### 3. 祝融赤火晶柱 (`FIRE_PILLAR`)
- **地貌特征**：地火地脉喷涌凝结的赤红色六角火灵晶柱，内部岩浆流淌，散发炽热光晕。
- **战术机制**：阻挡寻路。当被击退单位撞击到火晶柱上时，触发【火晶殉爆】，对撞击目标附加【真火灼烧】Debuff（每回合损失 8 点气血，持续 2 回合）。

### 4. 太阴玄冰极刺 (`FROST_SPIKE`)
- **地貌特征**：九幽玄冰在地表凝结出的幽蓝色尖锐冰锥，冷气森然，周围地面凝结白霜。
- **战术机制**：阻挡寻路。敌人被撞击或击退至玄冰刺时，遭受【极寒穿刺】，下回合移动步法强制降低 1 格。

### 5. 幽煞剧毒荆棘 (`THORN_VINES`)
- **地貌特征**：缠绕着墨绿色剧毒煞气的荒古毒藤，长满倒刺，毒汁滴落处草木皆枯。
- **战术机制**：阻挡寻路。撞击壁击附加【腐骨尸毒】，削减目标 30% 基础护甲，持续 2 回合。

## 四、 五大山海秘境场景与法则增益系统

每场战斗开局，系统从五大秘境场景中动态加载（或根据章节剧情固定配置），赋予棋盘专属的暗部色调、棋盘边框与天地法则增益：

```
       五大秘境场景
   ┌────────────────────────────────────────────────────────┐
   │ 1. 通天剑冢 · 万剑归宗 (SWORD_TOMB)   金系/暴击率大涨  │
   │ 2. 祝融火谷 · 焚世地脉 (MAGMA_VALLEY) 火系加深/壁击灼烧│
   │ 3. 太古建木 · 青帝神林 (ANCIENT_FOREST)木系射程/回春自愈│
   │ 4. 太阴寒潭 · 九幽玄冰 (GLACIAL_ABYSS)水系减耗/暴击减免│
   │ 5. 昆仑仙府 · 太极两仪 (KUNLUN_TAIJI)  相克翻倍/背刺必暴│
   └────────────────────────────────────────────────────────┘
```

1. **通天剑冢 · 万剑归宗 (`SWORD_TOMB`)**：
   - **基调**：冷峻幽蓝剑气暗色背景 (`#0a121a`)。
   - **法则增益**：金系与剑道威能+25%，物理攻击暴击率+15%。
2. **祝融火谷 · 焚世地脉 (`MAGMA_VALLEY`)**：
   - **基调**：赤红焦土熔岩背景 (`#1a0a0a`)。
   - **法则增益**：火系神通威能+30%，产生击退或撞墙壁击时附加灼烧真火伤害。
3. **太古建木 · 青帝神林 (`ANCIENT_FOREST`)**：
   - **基调**：苍翠幽静古木深林 (`#08170e`)。
   - **法则增益**：木系神通射程+1；每候回合伊始，全体修仙同盟自愈+12气血。
4. **太阴寒潭 · 九幽玄冰 (`GLACIAL_ABYSS`)**：
   - **基调**：冰魄晶莹深潭冷色 (`#08121d`)。
   - **法则增益**：水系神通真元消耗-1；全体受到的暴击伤害减免30%。
5. **昆仑仙府 · 太极两仪 (`KUNLUN_TAIJI`)**：
   - **基调**：紫极鸿蒙仙气两仪环绕 (`#120d1f`)。
   - **法则增益**：五行相克增伤提升至50%；绝脉背刺必暴伤害提升至160%。
