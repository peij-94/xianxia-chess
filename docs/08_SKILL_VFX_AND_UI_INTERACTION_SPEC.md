# 《山海问道录·天衍棋局》游戏设计案 —— 第八卷：全技能修仙高阶神通特效与 16-Bit 像素战棋交互规范

## 一、 系统定位与重构目标

在战棋（SRPG）游戏中，**操作的流畅度**与**技能释放的视听冲击力**是决定玩家沉浸感的核心支柱。
针对早期版本中“弹窗遮挡攻击选点”、“棋盘视界局促”、“技能特效偏离文字描述”以及“特效缺乏像素质感”等问题，本作完成了全方位的战棋交互体系与高阶神通特效系统（SkillVFX）重构：

1. **界面视界与尺度重构（1.5 倍黄金放大）**：将棋格与角色视觉放大 1.5 倍至 48px，右侧详情面板瘦身紧凑排版，隐藏冗余移动轨迹线，让大荒棋盘视野纯净清爽。
2. **交互生命周期与智能防遮挡**：角色选定唤起悬浮灵符菜单，选定法术技能后**弹窗立即自动收起**，为玩家完整露出棋盘目标点；支持右键与空地多级智能撤销。
3. **100% 严密贴合技能描述的高阶修仙特效**：杜绝扁平光束线条，完全采用 **16-bit 国风像素美学（Pixel Art VFX）**、2px 整数网格对齐与多级色阶分层渲染。

## 二、 棋盘视界与交互界面重构规范

### 1. 尺度参数与布局规范
- **棋盘规模**：`20 × 20` 大尺度天衍棋局（标准宏大遭遇战地貌）。
- **棋格放大至 1.5 倍**：
  - 基础棋格尺寸：由原先的 32px 提升至 **48px** (`TILE_SIZE = 48.0`)。
  - 棋盘起始坐标：`BOARD_ORIGIN = Vector2(24, 76)`。
  - 角色精灵、本命神兵法宝、选中光环与受击判定同步等比放大 1.5 倍，细节纤毫毕现。
- **右侧详情栏瘦身与紧凑排版**：
  - 固定宽度压缩至 320px，腾出超 70% 屏幕面积作为核心交锋战区。
  - 采用仙侠折叠卷轴卡片设计，角色气血条、灵气槽、境界称号与配备神兵整齐收纳。
- **移动轨迹线隐去**：
  - 彻底去除传统战棋在角色身后绘制的杂乱移动折线与虚线，仅保留明晰的高亮可移动范围网格（青绿灵光），确保全图战术意图清爽一目了然。

### 2. 悬浮灵符选单（Floating Action Menu）生命周期与防遮挡机制
传统 RPG/SRPG 常出现的痛点是：点击技能后，弹出的列表仍遮挡在棋盘前方，挡住了关键打击位置。本作实现了全新的状态机闭环：

```
   ┌────────────────────────────────────────────────────────┐
   │               【状态 1：点击选中角色】                  │
   │  棋盘高亮可移动地格 (青绿)，角色身侧弹出悬浮灵符操作菜单  │
   │  包含：【移动】、【防御】、【功法1】、【功法2】、【取消】│
   └───────────────────────────┬────────────────────────────┘
                               │
                      选择攻击/施法功法
                               │
                               ▼
   ┌────────────────────────────────────────────────────────┐
   │          【状态 2：技能锁定阶段（自动收起弹窗）】       │
   │  1. 悬浮灵符菜单瞬间自动隐藏 (visible = false)         │
   │  2. 棋盘立即全景展露，高亮可打击射程与 AOE 范围 (赤红)  │
   │  3. 玩家视野毫无遮挡，可精准点击敌方目标或地格施法     │
   └───────────────┬────────────────────────┬───────────────┘
                   │ 点击目标释放           │ 右键或点击空白取消
                   ▼                        ▼
   ┌───────────────────────────┐    ┌───────────────────────────┐
   │      【释放神通特效】      │    │    【多级智能撤销】       │
   │  触发 16-Bit 高阶神通演武  │    │ 还原至选角色或完全取消     │
   └───────────────────────────┘    └───────────────────────────┘
```

## 三、 全技能修仙高阶神通特效（SkillVFX）设计标准

特效核心实现类：[`SkillVFX.gd`](file:///Users/peij94/Documents/antigravity/修仙战棋/godot_project/scripts/vfx/SkillVFX.gd)。
全部神通演武持续时间由 `setup()` 精准驱动，根据技能位格定制持续时长（0.50s ~ 0.90s）。

### 1. 凌虚子【庚金破空剑】（SWORD，御剑飞刺穿心，击退1格）
- **技能描述**：*“御剑飞刺击退1格”*
- **视觉设计规范**：
  - **飞剑弹道阶段**（0.0s ~ 0.45s）：剑仙掐指御剑，太白飞剑剑身具双刃、剑脊极白锐芒、鎏金护手与剑镦，后方拖曳两道破空剑影残影疾驰贯穿。
  - **命中穿心与剑气爆散阶段**（0.45s ~ 0.85s）：目标身上爆开贯穿性的金色巨型十字剑芒，8 道放射状金光剑煞向外喷射，伴随击退半月形气浪。

### 2. 凌虚子【万剑归宗】（SWORDS_AOE，十字范围万剑暴击轰炸）
- **技能描述**：*“十字范围万剑暴击轰炸”*
- **视觉设计规范**（**彻底告别光束线条，完全采用剑影实体**）：
  - **八卦剑阵锁定**（0.0s ~ 0.3s）：十字 5 个受击格地面亮起旋转金色八卦阵盘，八角阵纹流光飞速运转。
  - **九天万道剑影斜插大地**（0.3s ~ 0.7s）：22 柄精细剑形构造的庚金仙剑剑影从九天高空以大倾角呼啸斜插大地（双刃阳面银白、阴面沉金、白光剑脊、鎏金护手）；每柄剑下落带有 2 道半透明破空残影。
  - **斜插地面与剑鸣爆震**（0.7s ~ 0.9s）：仙剑半截没入地面斜插，剑身带着剑鸣振颤抖动，地面连续激荡金色环形剑气冲击波。

### 3. 毕方【独足赤羽焰】（FIRE，三昧灵火喷吐）
- **技能描述**：*“三昧灵火喷吐”*
- **视觉设计规范**（**纯正 16-bit 像素火龙 + 呼啸后掠赤羽尾焰 + 翻旋火羽**）：
  - **对齐网格**：全图元严格对齐 2px 整数像素方块，杜绝平滑抗锯齿矢量。
  - **火龙躯干喷涌**：28 节阶梯像素方块组成翻滚火柱，由外及内展现五层分阶像素（焦黑烈煞 `#7f1d1d` → 朱红 `#dc2626` → 离火橙红 `#ea580c` → 三昧赤火 `#f97316` → 白炽极热 `#fef08a` 与纯白）。
  - **呼啸后掠赤羽尾焰**：在火龙两侧沿 135° 与 225° 后掠角密集掠起羽片状阶梯火焰，模拟神鸟振翼喷吐的尾焰。
  - **翻旋独立赤羽**：气流中伴随 12 枚独立自旋的像素火羽（每枚火羽具羽轴、羽腹、金炽羽梢三层结构）随风舞动。
  - **命中轰天爆裂**：火龙贯穿触达目标，环形像素火海与 8 朵放射状激射的毕方赤羽轰然爆散，地面留下熔岩焦土裂纹。

## 四、 动画逐帧录制与媒体压制规范

为确保设计效果能够即时实机审查、对外展示与汇报，工程内置了自动化录制与转码管线：
1. **实机逐帧录制**：
   - 启动环境变量：`RECORD_SKILL=1`；
   - 自动在 Godot 运行时截取每帧视口贴图并存入 `/tmp/skill_frames/frame_*.png`。
2. **视频与动图压制管线**：
   - 利用 Python `imageio` 与 `imageio-ffmpeg`；
   - 帧率：20 FPS（保证像素动画质感与流畅节奏）；
   - 输出两种规格：
     - **全景实机视频/动图**（1440×1050）：包含完整 HUD、行动栏与宏大棋局。
     - **核心特写视频/动图**（480×480）：裁剪施法者与目标交锋的核心网格，特写展示像素火羽与剑影细节。
