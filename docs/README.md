# 《山海问道录·天衍棋局》游戏策划与设计案全卷导航 (GDD Index)

本项目为基于《山海经》古典神话与东方玄门修仙文明的 16-Bit 像素策略战棋游戏（SRPG）。
本地仓库 `docs/` 目录下收录了完整的游戏策划设计案（GDD 共八卷），涵盖世界观、核心战术机制、角色图鉴、像素美术规范、Godot 架构落地、神兵法宝、四时天象与障碍物、高阶神通特效与交互规范：
